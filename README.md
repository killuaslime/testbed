# Testbed

A 2D game development project built with **C++** and **SFML**.

Testbed is a playground for experimenting with game architecture, rendering, player systems, and gameplay mechanics. The project is evolving toward a single-player tactical roguelite with AI-controlled opponents and progression.

## Features

- 2D rendering with SFML
- Player entities and team organization
- Custom rendering system
- Early-stage gameplay and simulation experiments

## Planned Features

- [ ] Map loading and rendering
- [ ] Team-specific spawn points
- [ ] Round-based gameplay
- [ ] AI-controlled opponents
- [ ] Player movement and combat
- [ ] Tactical roguelite progression
- [ ] In-game UI and HUD

## Built With

- **C++** — core game logic
- **SFML** — graphics, window management, and input

## Project Status

**In development.**

The project is currently focused on establishing the core architecture and building the foundation for future gameplay systems.

## Goals

The goal of Testbed is to grow from a simple game development sandbox into a playable tactical roguelite while keeping the codebase modular and maintainable.
